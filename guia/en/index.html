What it is

A method, not a trick

Ten steps that go from an X-ray of your site to notifying the search engines, with ready-made scripts and templates you adapt to your own site.

🧱 Foundation first

A single canonical, sitemaps with language, robots that let the AIs in, llms.txt and thin pages kept out of the index. Without this, no content pays off.

🧾 Real data only

Every page is backed by a course, project, event or experiment that exists. The LLM extracts and rewrites; a validator discards whatever is not in the source.

📏 Measured without the brand

The number that matters is searches that do not include your name: people who did not know you and found you. The weekly export separates them out.

The method

The 10 steps

In the order we apply them. The details of each one are in docs/METODO.md (in Portuguese).

1 Audit→ 2 Technical foundation→ 3 Brand-free measurement→ 4 Entity→ 5 One territory per site→ 6 Original content→ 7 Hubs and internal links→ 8 Backlinks→ 9 News with a page→ 10 Notify and follow up

1 · Real audit

Look at the HTML the server delivers: canonical, hreflang, JSON-LD and how many internal links exist. A page with no links is a page that barely exists.

2 · Technical foundation

One canonical only (www or not), a sitemap with real lastModified, robots letting the AI crawlers in, llms.txt and a content-index.json manifest per site.

3 · Brand-free measurement

A weekly Search Console export that separates brand searches, URL inspection and a conversion goal in analytics.

4 · Entity

A Person and an Organization with a fixed @id, cited by every page and every subdomain.

5 · One territory per site

Evergreen guide on the main site, news on the news site, events on the events site. One owner page for each search intent.

6 · Original content

Pillars, question pages with a direct 40–60 word answer, and fact sheets with data extracted from the real page. Keywords validated by score, no paid tool.

7 · Hubs and internal links

A ladder of links for every new page and hub pages that read the other sites' manifests. A search page keeps an index of links in the HTML.

8 · Backlinks

Each satellite (course, landing page, README) links to the right page on the main site, in batch and with a dry run.

9 · News with a page

One URL per news item and language, NewsArticle, an archive that is never pruned, and a minimal body written only with facts from the source.

10 · Notify and follow up

IndexNow and Bing on every publish (ChatGPT and Copilot use Bing's index), sitemap in Search Console and a weekly read.

Prerequisites

What you need

Everything is free. The search accounts need the site to be verified.

Google Search Console

A verified domain property and gcloud with application credentials, for the measurement scripts.

gcloud auth application-default login \
  --scopes=https://www.googleapis.com/auth/webmasters.readonly,\
https://www.googleapis.com/auth/cloud-platform

Bing Webmaster + IndexNow

Site verified on Bing (you can import it from Search Console) and an IndexNow key published at the root of the site.

# public key: https://yoursite.com/<key>.txt
openssl rand -hex 16

Local tools

git, curl, Python 3 and Node 18+. An AI agent (Claude Code or Codex CLI) for the extraction and writing steps.

git clone https://github.com/inematds/inemaseo-metodo
Step by step

Applying it to your site

The commands are the scripts in this repository. Replace seusite.com with your own domain.

1

Take the X-ray

Redirects, robots, sitemaps, llms.txt and, per page, title, canonical, hreflang, JSON-LD and internal links in the HTML.

bash tools/auditoria.sh https://www.seusite.com /catalogo/ /sobre/  # report in the terminal
2

Fix the foundation

Use the templates: templates/robots.txt, templates/llms.txt, templates/content-index.json and templates/jsonld-entidade.json. Canonical, sitemap and JSON-LD on the same host.

# after publishing, confirm
bash tools/auditoria.sh https://www.seusite.com
3

Start measuring without the brand

Run it every week. It produces a CSV of non-brand queries and one summary row per week and site.

export GSC_SITES="sc-domain:seusite.com" GSC_MARCA="seusite|seu nome" GSC_QUOTA_PROJ="seu-projeto-gcp"
python3 tools/gsc_semanal.py --dias 7  # dados/gsc/resumo.csv
4

Pick pages by score

Autocomplete, Google Trends, impressions you already have and the strength of the top 10. GO at 6 points or more, and only if there is a real asset to cite. Table in docs/METODO.md.

# queries with impressions and no dedicated page = validated topic
sort -t, -k4 -nr dados/gsc/*_sem-marca.csv | head -30
5

Write with an anti-invention lock

The LLM extracts from the real page (templates/prompt-ficha-extrativa.md, templates/prompt-texto-noticia.md); the validator discards any sentence with no support in the source and any number that does not appear in it.

node tools/validar_extracao.mjs fonte.txt "Curso com 5 módulos e 12 horas"
# { apoiada: true, numerosNaFonte: false, ... }  → discard
6

Link the satellites to the main site

A JSON file with repo and target page. Dry run first; then --apply --commit.

python3 tools/link_de_volta.py mapa.json --guia https://www.seusite.com/aprender/ --guia-rotulo "Guia completo"
python3 tools/link_de_volta.py mapa.json --apply --commit
7

Publish and notify the search engines

Only URLs that return 200. The script checks first, then sends to IndexNow and, if you have a key, to Bing.

INDEXNOW_KEY=<key> BING_API_KEY=<key> bash tools/avisar_buscadores.sh urls.txt
# IndexNow: HTTP 200 · Bing SubmitUrlBatch: HTTP 200
8

Check indexing and repeat

Ask Google for the status of each new page; the ones that do not show up get internal links and an indexing request in the console. Before publishing, run the quality checklist (in Portuguese).

python3 tools/gsc_inspecionar.py sc-domain:seusite.com https://www.seusite.com/nova-pagina/
# Submitted and indexed | crawled 2026-10-01 | Google canonical ...
